MAGICK SHOP McALLEN - JULIO OVALLE

Open index.html in a browser to view the assignment.
Files: index.html, style.css, script.js, and assets/ (offline image backups).

Layout recreated from the classroom Bootstrap sample at:
https://nhinojosa.github.io/bootstrapdemo/index.html

The image URLs use the classroom sample images and require an internet connection. If an image cannot load, a local illustration will appear instead. Bootstrap also loads from a CDN.

To publish to GitHub Pages:
1. Create a GitHub repository (example: julio-ovalle-bootstrap).
2. Upload all files and the assets folder into the repository root (not the ZIP itself).
3. Go to Settings > Pages > Deploy from a branch > main > / (root) > Save.
4. Once published, copy the live URL in the assignment comments.
